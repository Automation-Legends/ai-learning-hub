# Week 4 Capstone Social Launch Kit

Use this kit to announce the Week 4 collaborative capstone: the **Community Resource Review Assistant**. Replace bracketed details before posting. All versions describe the project accurately: it prepares a structured draft for moderator review; it does not publish content automatically, make final decisions, or require members to build a live production system.

> **Publishing principle:** Invite members to learn and contribute. Do not promise outcomes, use fake scarcity, imply that participation is required, or share member work without permission.

## Core message

**Main idea:** Week 4 turns individual AI learning into a collaborative, real-world project. Beginners and intermediate builders contribute different skills to create a safer, reviewable workflow for community resource suggestions.

**Primary link:** https://github.com/Automation-Legends/ai-learning-hub/blob/main/community/week-04-collaborative-capstone.md

## LinkedIn announcement

```text
Week 4 of the Automation Legends AI Learning Hub is now open.

This week, members move from individual AI practice to a collaborative capstone: the Community Resource Review Assistant.

The project addresses a real community need. When someone suggests an AI-learning resource, the workflow prepares a structured draft with a summary, possible tags, verification questions, concerns, and a clear review flag. A human moderator remains responsible for every approval.

There is a meaningful role for every member.

Beginners can define learner needs, improve prompts, test safe examples, review outputs, and document the experience. Intermediate builders can map the workflow, design structured outputs, define safe integration boundaries, test exceptions, and prepare a review queue.

The goal is not an autonomous publishing tool. The goal is a safe, transparent, draft-and-review workflow that the community can test and improve together.

A live deployment is optional. A clear design, five-case test set, honest limitation, and useful reflection are valid capstone outcomes.
```

## Community-platform announcement

```text
## Week 4 capstone is open: Build a Community Resource Review Assistant

This week, we are building a safe, collaborative workflow that prepares review drafts for AI-learning resource suggestions. The goal is to help moderators and members organize, verify, and improve resource submissions—not to publish automatically or make final decisions.

Choose a role that matches what you want to practice:

| Role | You can contribute by… |
|---|---|
| Community researcher | Defining learner needs and reviewing resource quality criteria |
| Prompt designer | Writing and improving the structured review prompt |
| Quality reviewer | Testing typical, incomplete, ambiguous, boundary, and messy cases |
| Documentarian | Explaining the workflow, limits, and member experience clearly |
| Workflow builder | Mapping the trigger, structured output, review queue, and fallback |
| Evaluator | Recording results, handling exceptions, and naming a focused improvement |
| Moderator owner | Confirming approval standards and the human escalation path |

Start with the [capstone module](week-04-collaborative-capstone.md) and review the [feedback and grading rubric](week-04-capstone-feedback-and-grading-rubric.md).

Reply with the role you would like to explore and one question you want the team to answer.
```
