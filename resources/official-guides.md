# Official Guides and Continuing Resources

This page links to primary-source material that can help you continue learning after the Automation Legends paths. Tools and model capabilities evolve quickly, so prefer the official documentation for the service you use and revisit it before building a production workflow.

> **Use these resources to deepen your practice, not to skip evaluation.** A technique that works in one model or version still needs testing in your own use case.

## Prompting and workflow design

| Resource | Best for | Why it is useful |
|---|---|---|
| [OpenAI — Prompt engineering](https://developers.openai.com/api/docs/guides/prompt-engineering) | Structuring instructions, examples, context, and output formats | Discusses prompt techniques and recommends tests and evaluations for complex applications. [1] |
| [Anthropic — Prompt engineering overview](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview) | Defining success criteria before prompt refinement | Emphasizes clear success criteria, ways to test them, and a first-draft prompt before optimization. [2] |
| [Anthropic — Interactive prompt-engineering tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial) | Hands-on practice with examples | Provides a step-by-step tutorial for practicing prompt-engineering concepts. [3] |

## Responsible AI and risk management

| Resource | Best for | Why it is useful |
|---|---|---|
| [NIST — AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework) | Understanding trustworthy-AI considerations | Provides a voluntary framework for incorporating trustworthiness considerations into the design, development, use, and evaluation of AI systems. [4] |
| [NIST — Generative AI Profile](https://doi.org/10.6028/NIST.AI.600-1) | Exploring generative-AI risks and risk-management actions | Companion resource to the AI RMF that focuses on risks unique to or amplified by generative AI. [5] |

## Learning practice

Do not try to read everything at once. Use the resource that matches your next task. For a prompt that is not producing a useful result, first clarify the goal, context, constraints, and output format. For a workflow that produces inconsistent results, define success criteria and test five representative cases. For a task with sensitive information or a higher consequence, narrow the AI role and strengthen human review before you connect more systems.

## Suggested community study sessions

| Session | Activity | Outcome |
|---|---|---|
| Prompt clinic | Members bring sanitized, real prompts and revise them using the prompt template | Each participant leaves with a tested improvement |
| Verification lab | Members audit a low-risk AI answer against reliable sources | Participants practice spotting unsupported claims and weak citations |
| Workflow-mapping workshop | Members complete the workflow canvas for one recurring task | Each participant identifies a bounded AI opportunity and review point |
| Evaluation review | Members test a prompt on normal, incomplete, ambiguous, boundary, and messy cases | Participants leave with an evidence-based next revision |
| Project showcase | Members share what worked, what failed, and the safeguards used | Community knowledge accumulates without hype or sensitive data |
