# Advanced Path

The Advanced Path is for members who can already design and test a bounded AI workflow and now want to work with custom agents, retrieval systems, and more complex integrations. Advanced work is not defined by a larger prompt or a more autonomous tool. It is defined by stronger system boundaries, evidence, evaluation, access controls, and accountable ownership.

> **Entry standard:** Complete the four-week AI Learning Hub pathway, including workflow design, evaluation and safeguards, advanced custom-agent boundaries, and the collaborative capstone, before beginning the post-program multi-agent module.

## What advanced practice requires

| Principle | In practice |
|---|---|
| **Narrow authority** | Give an agent only the tools, data, and actions required for one useful task. |
| **Approved knowledge** | Index only authorized, reviewed material and record where it came from. |
| **Visible evidence** | Return source links, citations, or retrieved passages that allow people to check the answer. |
| **Human accountability** | Pause for review before consequential actions and define who owns exceptions. |
| **Evaluation before expansion** | Test normal and adversarial cases before adding more sources, tools, users, or autonomy. |
| **Operational care** | Protect secrets, use least-privilege access, monitor failures, and maintain a rollback or fallback. |

## Start safely

Choose a read-only project first. Good examples include a resource-guide agent that points members to approved learning materials, a knowledge-base assistant that answers from a small public document set, or an internal drafting assistant that creates reviewable summaries from authorized data. Do not begin with autonomous publishing, payments, eligibility decisions, security actions, or access to private data.

## Completion standard

An advanced module is complete when you can show the system boundary, source governance, test evidence, human-review policy, and one honest limitation. A live deployment is optional. A thoughtful, well-tested design is the required outcome.
